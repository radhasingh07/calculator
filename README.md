# 🧮 Calculator

A responsive Calculator built using HTML, CSS, and JavaScript. This web application performs basic arithmetic operations through a clean, modern, and user-friendly interface.

## ✨ Features

- Addition, subtraction, multiplication, and division
- Clear (C) button
- Delete (⌫) functionality
- Decimal number support
- Responsive design
- Simple and intuitive user interface
- Real-time calculations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 📂 Project Structure

Calculator/

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
